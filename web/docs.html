How it works

DL Traffic records every request to the dliu.com sites in one place: when it happened, which IP it came from and which browser sent it. No site runs extra code and nothing runs while nobody is visiting.

Bot detection

How DL Traffic tells bots from people. CloudFront does not flag bots, so the dashboard combines one instant check on each request with a daily job that judges every IP address.

Running costs

What DL Traffic costs to run, and why. Nothing runs while nobody visits; every part is billed per use, and at the traffic of the dliu.com sites the whole monitor costs about $0.23 a month.

Security review

How DL Traffic is protected, what was tested against the live site and which risks are knowingly accepted.
