How it works

DL Traffic records every request to the dliu.com sites in one place: when it happened, which IP it came from and which browser sent it. No site runs extra code and nothing runs while nobody is visiting.

Bot detection

How DL Traffic tells bots from people. CloudFront does not flag bots, so the dashboard combines one instant check on each request with a daily job that judges every IP address.

Cost

What DL Traffic costs to run, and why. Nothing runs while nobody visits; every part is billed per use, and at the traffic of the dliu.com sites the whole monitor costs about $0.23 a month.

Security review

How DL Traffic is protected, what was tested against the live site and which risks are knowingly accepted.

How this site is tested

Every 15 minutes status.dliu.com visits this site as a guest, without signing in, from Ireland, Virginia and Tokyo. It opens the public pages, asks the site to check its own storage and scheduled jobs, then marks each function as working, slow or not working.

The site counts as down when Pages or Request logging stops working; when anything else stops working it counts as partly working.

What isn't tested

  • The full dashboard you only see after signing in.
  • The Check bots now button and the IP reputation lookups: they need a sign-in, and the free lookups per day are limited.
  • The reports the small script sends back: a test report would count as a real visit.
  • Finishing the sign-in at Microsoft: it needs an approved account.
  • The daily merge of visit records and the monthly city database download are seen only indirectly: when they break, the public numbers or the bot check go out of date.
